Settings → Performance mode

Two paths through the void

Void lets you choose how pages are drawn. Same privacy engine either way — different cost to your GPU and battery.

Default

Performance

Prefers GPU / hardware acceleration when the OS webview supports it. Smoother scrolling, richer media, and lower CPU load on machines with a capable GPU.

This is the everyday path: WebView2 and WebKitGTK use hardware compositing so the browser chrome stays light while pages render where your system is strongest.

config.toml → performance_mode = "performance"

Power-saving

Efficiency

Prefers the software rendering path — lower GPU use, better for laptops on battery, VMs without a GPU, and remote desktops.

On Windows this maps to WebView2’s disable-gpu path; on Linux it prefers WebKit’s software path (same idea as VOID_SOFTWARE_RENDERING=1). A restart may be needed for the full effect after switching.

config.toml → performance_mode = "efficiency"

Flip it anytime under Settings. Your choice stays local in config.toml — nothing is reported back. Privacy features stay on in both modes.

Built-in ad blocker

Same engine family as Brave. Blocks ads, trackers, and malware domains with 137,000+ filter rules. No extensions required.

HTTPS-only mode

Strict HTTPS by default. Insecure connections are blocked, not merely warned about. Your traffic stays encrypted in transit.

Anti-fingerprinting

Canvas, WebGL, and AudioContext resistance built in. Sites can’t stitch a unique browser profile to follow you around.

Zero telemetry

No usage analytics. No crash reports sent home. Nothing leaves your machine. We literally can’t see what you browse.

Tiny & fast

Under 10MB installed. Uses your OS native webview instead of shipping Chromium. Starts quickly. Uses less memory.

DNS over HTTPS

Encrypted DNS with Quad9, Cloudflare, or Mullvad. Your ISP can’t sell a log of every name you resolve.

WebRTC leak protection

Stops WebRTC from leaking your real IP — even behind a VPN. Off for non-proxied connections by default.

Fully customizable

Dark, Light, System, and Midnight themes. Custom CSS. Configurable keybinds. A plain-text config file you own.

  • Screen dimension masking

    FAQ

    Questions

    Is Void really free?

    Yes. Free as in freedom. GPL-3.0 licensed. No premium version. No paid features. Ever.

    Does Void auto-update?

    Yes, optionally. The app can check GitHub Releases for a newer version and offer Install & Relaunch. Every update package is signature-verified against a pinned public key before install — unsigned or tampered updates are rejected. That HTTPS check is the only update-related network call — still zero telemetry.

    What engine does it use?

    Void uses your operating system's native webview — WebView2 on Windows and WebKitGTK on Linux. No bundled Chromium.

    What’s Efficiency vs Performance?

    Performance prefers GPU / hardware acceleration. Efficiency prefers power-saving software rendering (WebView2 disable-gpu / WebKit software path). Switch in Settings; stored as performance_mode in your local config. See Modes.

    Why is it so small?

    Most browsers ship an entire copy of Chromium (~150MB). Void uses the webview your OS already has, so we only ship the browser chrome and privacy engine.

    Will it break websites?

    In Standard mode, almost never. Strict mode may block some third-party widgets. Paranoid mode disables JavaScript by default — some sites will need manual exceptions.

    How do I report a bug?

    Open an issue on our GitHub repository. We read every one.

    Can I contribute?

    Absolutely. Pull requests welcome. Check the README for build instructions and contribution guidelines.
